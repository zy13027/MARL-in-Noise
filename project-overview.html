University research project · MATLAB R2022a and Simulink

MARL-in-Noise

Two reinforcement-learning agents learn to cooperate when every message between them passes through a noisy channel. The Guide sees the whole map but cannot move. The Scout moves, but only knows what the Guide tells it.

  • 2 agents
  • 8 messages
  • 4 bits → Hamming (7,4)
  • BSC · AWGN + BPSK · AWGN + 8-PSK
  • 64 × 64 grid

Signal chainOne step of the loop the Simulink model runs, at a sample time of 0.1 s.

Both agents share one reward from the grid world, so the Guide only scores when the Scout acts on what it heard. The research question is how channel noise changes what the pair learns to say and do.

StatusFrom the September 2026 review. The full list with fixes is in docs/REVIEW.md.

Fixed and tested

  • FixedGridWorld no longer crashes with one robot, and diagonal moves no longer leave the grid.
  • FixedOutput sizes follow the grid (64 × 64 × 4) instead of the example's 12 × 12 × 4 × 3.
  • FasterPlotting is off by default. It used to redraw the grid on each of the first 500 steps of every episode.
  • RebuiltCustomGridWorld is now a small subclass with goal cells. The old version could not run.
  • Rebuiltdeconvert, simouttodec and ResetFcn are now plain .m files that run. act1Conv is a single vectorised line.
  • TestedUnit tests pass. On about 16,000 random steps, the new code matches the original MathWorks environment exactly.

Getting startedNeeds MATLAB R2022a or later with Simulink and the Reinforcement Learning, Deep Learning and Communications toolboxes.

cd MARL-in-Noise
setupProject                 % add folders to the path
results = runtests("tests")  % check the environment and helpers
open scripts/DraftV2.mlx     % build the Guide agent and open the model

GridWorld and ResetFcn are adapted from the MathWorks multi-agent area coverage example.
